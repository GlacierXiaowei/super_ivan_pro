# SuperIvanPro Windows 便携包使用说明

这个版本是给 Windows 测试用户用的便携包。

正常情况下，用户不需要再手动配置 `wechat-decrypt` 路径，因为这个运行时已经随文件夹一起打包。Python 不再内置在便携包里，测试电脑需要先安装 Python 3。

## 你应该先看什么

便携包根目录里你只需要关注这几个文件：

```text
super_ivan_pro.exe
首次初始化.bat
重启后台.bat
重建聊天缓存.bat
使用说明.md
```

## 第一次使用怎么做

1. 先把整个文件夹完整解压到本地磁盘。
2. 不要只拿出里面的 `exe` 单独运行。
3. 先登录 Windows 微信桌面版。
4. 双击 `首次初始化.bat`。
5. 再双击 `super_ivan_pro.exe` 打开程序。

## 三个脚本分别是干什么的

`首次初始化.bat`

- 第一次使用时先运行一次。
- 它会把本机 `%LOCALAPPDATA%` 里的运行配置指向当前这个便携包里的 `runtime\wechat-decrypt`。
- 如果你以后把整个便携包移动到别的位置，应该再运行一次这个脚本。

`重启后台.bat`

- 当程序里本地服务状态异常、卡住、没有拉起后台时使用。
- 它会重启本地 Python desktop service。
- 这个脚本不会主动去操作微信窗口，也不会自动帮你触发发送。

`重建聊天缓存.bat`

- 当历史群聊搜索、历史群成员搜索结果不全，或者缓存太旧时使用。
- 它会调用包内 `wechat-decrypt` 重新解密并刷新本地聊天缓存。
- 这个过程可能比较慢，属于正常情况。

## 这个版本默认还需要什么前提

这个版本仍然需要这些前提：

1. 电脑是 Windows。
2. 已经安装并登录 Windows 微信桌面版。
3. 已经安装 Python 3，并且命令行里能运行 `python` 或 `py`。
4. 解压目录有正常读写权限。
5. 第一次运行时如果 Windows 弹出安全提示，需要按实际情况允许执行。

如果脚本提示找不到 Python，请先安装 Python 3；如果你使用自定义 Python 路径，可以设置环境变量 `SUPER_IVAN_DESKTOP_PYTHON` 指向 `python.exe`。

## 遇到问题时的顺序

1. 先确认已经登录 Windows 微信。
2. 再重新运行一次 `首次初始化.bat`。
3. 如果程序状态还是不对，运行 `重启后台.bat`。
4. 如果历史聊天搜索不全，运行 `重建聊天缓存.bat`。

## 一个重要提醒

不要随便删除便携包里的 `runtime`、`data`、`tools` 文件夹。

程序不是只靠 `super_ivan_pro.exe` 一个文件运行的，必须保留整个文件夹结构。
